CleanView – Site Element Remover

100% free and open-source Microsoft Edge extension that lets you hide ads, cookie banners, popups, sticky bars, floating buttons, newsletter boxes, recommended sections and other unwanted page elements.

No subscriptions. No premium features. No ads. No accounts. No tracking. No analytics. No network requests.

Everything runs locally inside your browser and only changes your own view.

Features

  • Visual element picker
  • Hide individual elements
  • Hide similar elements across a page
  • Undo and Restore All
  • Persistent website rules
  • Rules dashboard
  • Import / Export rules
  • Light & Dark themes
  • Keyboard shortcuts
  • Works with dynamic websites
  • Supports Edge, Chrome, Brave and other Chromium browsers

Open Source

Built using pure HTML, CSS and JavaScript. No frameworks, no dependencies and no build step.
