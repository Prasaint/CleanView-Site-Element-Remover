Privacy Policy

Last Updated: November 2026

CleanView – Site Element Remover respects user privacy. The extension does not collect, store, transmit, sell, or share any personal information.

Information We Collect

CleanView does not collect:

  • Personal information
  • Email addresses
  • Browsing history
  • Analytics data
  • Usage statistics
  • Tracking identifiers
  • Location information

Local Storage

The extension stores user-created rules and settings locally using the browser storage API. This data stays on the user's device and is never transmitted anywhere.

Network Requests

CleanView makes no external network requests and does not communicate with any server for analytics, advertising, tracking, or data collection.

Permissions

The extension uses browser permissions solely for its functionality:

  • storage – Save rules and settings locally.
  • activeTab – Access the active tab when requested by the user.
  • Content Scripts – Apply user-created hiding rules on web pages.

Third-Party Services

CleanView does not use Google Analytics, advertising networks, tracking services, or any third-party data collection services.
